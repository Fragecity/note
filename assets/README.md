# 素材来源

- `shlab-logo.png`：笔记首页的上海人工智能实验室图形标志，来自官方素材 https://www.shlab.org.cn/static/asset/img/share-logo.png 。通过 Typst 裁切显示图形部分。
- `shanghai-ai-lab.webp`：演示封面横版标志，沿用 `qc-pre`，原始来源 https://www.shlab.org.cn/static/asset/2025/imgs/logo_1.webp 。
- `SUSTech LOGO CN.svg`：南方科技大学标志，沿用本地 `qc-pre/asset/icons/` 素材。

Logo 仅作为个人模板的默认机构标志；可通过 `pre.with(logo-left: none, logo-right: none)` 关闭或替换。
